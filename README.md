## 🚀 Featured Project

### ⭐ Edge AI CNN Inference Engine on FPGA

A complete CNN inference pipeline implemented entirely in **Verilog HDL** and synthesized using **Xilinx Vivado 2026.1**.

Features include:

- 3×3 Convolution
- MAC Architecture
- Feature Map Generator
- ReLU
- Max Pooling
- Flatten Layer
- Dense Layer
- ArgMax Classifier
- Memory-Based Design
- RTL Simulation
- FPGA Synthesis
